```text

└── README.md
```

## 📁 Uploaded Files

## 📲 Download & Installation

To run this app on your Android device:

1. &nbsp;&nbsp;&nbsp;&nbsp;Download the `C1.apk` file directly from this repository onto your phone.
2.  &nbsp;&nbsp;&nbsp;&nbsp;Open the file on your device to begin installation.
3.  &nbsp;&nbsp;&nbsp;&nbsp;If prompted, allow your browser or file manager permission to "Install from Unknown Sources".
<br><br>
## 🛠️ Development & Editing

If you want to modify the application layout, buttons, or underlying logic:

1. &nbsp;&nbsp;&nbsp;&nbsp;Download the `.aia` source file from this repository to your computer.
2. &nbsp;&nbsp;&nbsp;&nbsp;Go to the MIT App Inventor companion website (http://appinventor.mit.edu/).
3. &nbsp;&nbsp;&nbsp;&nbsp;Navigate to Projects -> Import project (.aia) from my computer and select your file.
<br><br>
## 🚀 Features

* Directional control layout optimized for real-time mobile robot navigation.
* Clean data packet transmission setup designed for smooth microcontroller reception.
